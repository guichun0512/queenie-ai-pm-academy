動手練習

直接複製練習 Prompt 到 Claude。以下全部使用虛構資料。

練習 A｜讀懂 JSON

{ "order_id": "SP12345", "amount": 850, "payment_status": "failed", "retry_count": 3, "paid": false, "items": ["book", "pen"] }

找出：哪些是字串？哪些是數字？items 是什麼型態？若使用者說已付款，妳會先查什麼？

練習 B｜PM Issue 分析 Prompt

你是電商平台的 Product Manager 助手。請分析以下「完全虛構」的 Issue 資料。 目標：依付款、訂單、物流、帳號、其他分類；判斷可能影響；列出需人工確認的問題。 限制：不得虛構未提供的交易紀錄；若資料不足，請標示「待確認」。 輸出：表格（issue_id、分類、判斷依據、風險、待確認事項）＋分類數量統計。 驗證：逐筆列出來源 ID，總數必須與輸入筆數一致。 資料： 1. I001：付款頁面顯示失敗，但銀行已扣款 2. I002：買家查不到包裹物流更新 3. I003：賣家無法列印出貨單 4. I004：買家登入時出現錯誤 5. I005：取消訂單後退款狀態未更新

帳號與雲端同步

使用自己的 Google 帳號登入後，學習進度會儲存到 Firebase Firestore，並同步到其他已登入的裝置。登入前可先在本機使用，首次登入會合併本機與雲端已完成課程。

☁️ 同步狀態

尚未設定 Firebase：目前使用本機進度。

首次設定：Firebase 網站設定（只需要設定一次）

部署前請將 Firebase 專案的網頁應用程式設定填入下方，按「套用設定」。這些設定不是密碼；真正的存取保護由 Firebase Authentication 與 Firestore Security Rules 控制。

設定會保存在這台電腦的瀏覽器；另一台電腦可重新貼上設定。若要直接使用固定網址且免重設，請依部署教學把設定寫入網頁檔案中的 DEFAULT_FIREBASE_CONFIG。

離線可閱讀既有課程；雲端同步與 Google 登入需要網路及 HTTPS 網址。公司電腦需遵守企業登入與網站存取政策。
